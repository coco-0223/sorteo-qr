# Sorteo Fin de Año - Webapp QR

Aplicación web mobile-first para registrar participantes (Nombre y Apellido + Teléfono) directo en Google Sheets.

## Despliegue en Vercel

1. Importar el repositorio en Vercel.
2. En **Environment Variables**, configurar las credenciales de Google OAuth y el Spreadsheet ID.
3. Hacer clic en **Deploy**.
